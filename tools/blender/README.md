# Environment kit generators (60s main street)

Everything under `assets/buildings/`, `assets/props/`, `assets/materials/*.tres` and
`assets/textures/{generated,signs}/` is generated by these scripts. Rebuild all of it with:

```sh
tools/blender/build_all.sh          # ~40 s: textures, materials, buildings, props, Godot import
```

| Script | Runs with | Output |
|---|---|---|
| `gen_textures.py` | `python3` (Pillow) | painted interiors, lit windows, posters, ghost sign, awning canvas, optional shop signs |
| `gen_materials.py` | `python3` (Pillow) | `assets/materials/*.tres` from `materials_def.py` (+ greyscale albedo copies) |
| `buildings.py` | `blender -b --factory-startup --python` | `assets/buildings/*.glb` + `kit.json` |
| `props.py` | `blender -b --factory-startup --python` | `assets/props/*.glb` + `props.json` |
| `configure_imports.py` | `python3` | sets `import_script/path` of every kit `.glb.import` to `assets/buildings/kit_import.gd` |

* `kitlib.py` — geometry helpers (bevelled boxes, sweeps/mouldings, lathes, walls with reveals);
  takes game coordinates (+X walk, +Y up, +Z toward the camera) and writes metre-scale box UVs.
* `materials_def.py` — single material table. The .glb files carry only material *names*;
  `kit_import.gd` swaps each for `res://assets/materials/<name>.tres` at import time and turns
  `omni_*` marker empties into OmniLight3D nodes (group `kit_light`).
* PBR source textures are Poly Haven CC0 (1K), see `assets/CREDITS.md`.
* Visual check: `godot --path . --write-movie /tmp/kit/frame.png --fixed-fps 5 --quit-after 10
  res://assets/buildings/test/kit_preview.tscn` (user args after `--`: `--rain=0`, `--start=X`,
  `--step=M`, `--cam_z=Z`, `--cam_y=Y`, `--shot=props|car`, `--view=px,py,pz,lx,ly,lz;...`).
